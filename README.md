# Travel Planner

Учебный Frontend MVP Пан Романа Сергеевича, группа 242P. Приложение помогает заранее посмотреть время вылета и события по дням, чтобы не забывать о планах на путешествие.

Проект продолжает каркас ЛР2 из репозитория https://github.com/plozzz126/MVP. Основной функционал реализован по ЛР3. Интерфейс на русском языке; цвета из заполненной ЛР2: `#0f766e`, `#ccfbf1`, `#ffffff`.

## Запуск

Из корня репозитория `MVP`:

```bash
npm run setup
npm run dev
```

Нужны Node.js 22.12+ и npm ([требования Vite](https://vite.dev/guide/)). Адрес по умолчанию: http://localhost:5173.

В текущей рабочей среде Node.js подготовлен в `~/.local/share/travel-planner-runtime`. Скрипт запуска сам использует его, если Node.js отсутствует в PATH:

```bash
./start.sh
```

Из исходной папки с документами: `./MVP/start.sh`.

Приложение находится в `frontend/front`. Команды проверки из этой папки:

```bash
npm test
npm run build
```

Эти команды также доступны из корня `MVP`.

## Функции

| Возможность пользователя | Экран | Статус |
| --- | --- | --- |
| Просматривать 10 путешествий в карточках | Главная, Путешествия | Готово, ЛР3 |
| Открыть полную информацию, вылет и расписание по дням | Путешествие | Готово, ЛР3 |
| Найти поездку по названию, стране, городу или описанию | Путешествия | Готово, ЛР3 |
| Отфильтровать поездки: город, море, горы, природа | Путешествия | Готово, ЛР3 |
| Сортировать по длительности, бюджету, дате и названию; сбросить настройки | Путешествия | Готово, ЛР3 |
| Создавать и редактировать собственные поездки и события | Планирование | План, ЛР4 |
| Сохранять избранное | Избранное | План, ЛР4 |

Уведомления о вылетах и событиях, приглашение участников и голосования за маршрут — дальнейшие функции из исходного MVP-листа. Регистрация и вход также запланированы; серверной авторизации в этой части нет.

Все поездки, вылеты и бюджеты — демонстрационные данные. Приложение не получает реальные расписания авиакомпаний и не отправляет уведомления.

## Маршруты

| Адрес | Компонент | Назначение |
| --- | --- | --- |
| `/` | HomePage | Описание и 3 поездки с самой ранней датой начала |
| `/trips` | TripsPage | Карточки, поиск, фильтр, сортировка |
| `/trips/:tripId` | TripDetailsPage | Все поля поездки, расписание, вылет |
| `/favorites` | FavoritesPage | Экран для будущего избранного |
| `/about` | AboutPage | Идея, пользователь и этапы проекта |
| `*` | NotFoundPage | Неизвестный адрес и переход на главную |

В ЛР2 таблица экранов содержит `/favorites`, а таблица маршрутов — `/about`: сохранены оба экрана. Динамический параметр приведён к `tripId` из заполненного бланка. Ссылки на существующие поездки продолжают работать.

## Структура

```text
frontend/front/
├── public/illustrations/     локальные SVG-иллюстрации
├── src/
│   ├── components/           Layout, Header, Footer, TripCard, TripList,
│   │                        SearchBar, CategoryFilter, SortSelect
│   ├── data/trips.js         10 поездок, категории, getTripById
│   ├── pages/                6 страниц приложения
│   ├── utils/trips.js        поиск, сортировки и форматирование
│   ├── router.jsx
│   ├── main.jsx
│   └── index.css
└── tests/trips.test.js       проверки данных и работы с ними
```

`TripCard` получает данные через props. `TripList` использует `key={trip.id}` и показывает пустое состояние. Поиск, фильтр и сортировка — отдельные управляемые компоненты. Их state находится в `TripsPage`; видимый список вычисляется при отрисовке. Сортировка работает на копии массива. Обработаны неизвестные и нечисловые ID.

## Проверка для ЛР3

Данные для заполнения таблиц, сценарии самопроверки и оставшиеся материалы для сдачи перечислены в [docs/LR3.md](docs/LR3.md).

При размещении production-сборки на хостинге настройте fallback всех маршрутов на `index.html`, потому что используется `createBrowserRouter`. Локальный сервер Vite делает это автоматически.
